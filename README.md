# Eco Ponto Tech UGB

Projeto acadêmico desenvolvido no curso de Engenharia de Software do Centro Universitário Geraldo Di Biase (UGB), com o objetivo de conscientizar sobre o descarte correto de resíduos eletrônicos.

A aplicação web foi criada como complemento a uma maquete apresentada durante o trabalho. Por meio de um QR Code, os visitantes podem acessar informações sobre diferentes tipos de resíduos eletrônicos e orientações para seu descarte.

## Tecnologias utilizadas

- Python
- Flask
- HTML e CSS
- Vercel

## Acesso ao projeto

[Eco Ponto Tech](https://ecopontotech.vercel.app)

## Execução local

Com o Python instalado, clone o repositório e execute os seguintes comandos:

```bash
git clone https://github.com/catharinaoliveira/ecoponto_ugb.git
cd ecoponto_ugb
pip install -r requirements.txt
python -m flask --app app run
```

A aplicação estará disponível em `http://127.0.0.1:5000`.
